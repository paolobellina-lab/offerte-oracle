Importa dal file Excel

Carica il file Template_Import_Righe-OFFERTA (.xlsm o .xlsx). Si leggono i fogli catalogo, i capitoli con il ricarico automatico, i GMV e i cartellini clienti. Il file non viene modificato.

Aggiorna i prezzi da Oracle

Dalla griglia delle righe offerta di Oracle seleziona tutto e copia (con la riga delle intestazioni), poi incolla qui. Servono le colonne Codice Articolo Fornitore e Prezzo Unitario; se c'è la colonna GMA si aggiorna anche il GMV. Va bene anche un file Excel con le stesse colonne.

Copia di sicurezza

Scarica tutti i dati (catalogo, clienti, offerte) in un file da conservare, oppure ripristinali da una copia.
